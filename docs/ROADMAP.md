# 路线图:走向"接近临床医生的听诊效果"

> 定位:个人/研究/学习原型(非医疗器械、不涉监管)。ML 走公开数据集。

## 现状

已完成**筛查级**能力:心率 BPM、SQI 信号质量门控、HSMM-lite 心音分段、
节律分析(CV/Poincaré/早搏)、杂音能量提示。详见 [ALGORITHM.md](ALGORITHM.md)。

## 期望与现实的校准

临床医生听诊在做的远不止"测心率+发现杂音":识别 S1/S2、分裂、额外音
(S3/S4、click、开瓣音、心包摩擦音);刻画杂音的**时相/形状/强度分级/音调/
位置+放射**;并借**呼吸、Valsalva、体位**等动作做鉴别。

**关键判断:**
- 纯手写 DSP 规则会触顶,**到不了临床级**。真正接近临床靠
  **准确分段(DSP)+ 大型标注心音库上训练的 ML 模型**。
- 令人鼓舞的事实:PCG 上训练的 AI 在**杂音检测**一项上,可**达到甚至超过
  非专科医生**听诊。所以"接近临床"在**正常/异常、杂音有无**这层**可达**;
  复刻专科医生的**完整定性+定位+动作鉴别**目前**达不到**,且单麦克风单部位
  在物理上就缺了放射方向和动作维度。

## 分阶段路线(由实到虚)

### ✅ 阶段 1 — SQI 信号质量门控(已完成)
分析前剔除摩擦/运动/过载污染段,立刻降假阳。工程量最小、收益最快。

> 三处曾使门控在真实场景下失效、现已修复(详见 ALGORITHM.md §4):
> 削波在重采样**之后**判定(抗混叠会磨圆平顶,44kHz 输入时完全漏检);
> `band_ratio` 遇 50Hz 工频反而**升高**(与真实质量反相关);
> `predict.py` 完全不做门控(实时路径却做了),低质量录音也会得到自信判定。
> 现在 `analyze()` 统一给出 `reliable` 与 `unreliable_reason`,两条路径共用。

### ✅ 阶段 2 — HSMM 心音分段(已完成轻量无监督版)
时长约束的 S1→收缩→S2→舒张 分段,是所有下游临床特征的**地基**。
> 升级方向:接入有监督的 Springer 2016 逻辑回归发射模型(需标注训练),
> 在低 SQI / 心律失常下更稳。
>
> **这不只是"更稳"的问题,而是一个已知会出错的场景**:当前无监督发射模型以
> 包络高低区分"心音/间歇",杂音响过心音本体时会把杂音当成心音,收缩/舒张
> 窗口随之错位,**时相归属判反**(合成实验中舒张期杂音幅度 1.6 时被报成
> 收缩期杂音)。因为所有下游临床特征都建在分段之上,这是当前架构下最值得
> 优先攻克的一环。详见 ALGORITHM.md §9.2。

### ✅ 阶段 3 — 可解释临床特征(在准分段之上,已完成)
| 特征 | 医学依据 | 状态 |
|---|---|---|
| **STI / LVET** | S1–S2 间期 ≈ 左室射血时间,反映收缩力(Weissler) | ✅ 已实现(近似) |
| **标准时域 HRV** | RMSSD、pNN50、SDNN(Task Force 1996);严格需 ECG | ✅ 已实现 |
| **杂音时相+形状** | 递增-递减(钻石形)→主动脉狭窄;全收缩期平台→MR/VSD | ✅ 已实现(启发式) |
| **频域 HRV(LF/HF)** | 自主神经平衡;需 ≥1–2 分钟稳定记录 | ✅ 已实现(带门控) |
| **S3/S4 奔马律** | 舒张期低频(15–60Hz)额外音 → 心衰/心室僵硬 | ✅ 已实现(启发式) |
| **S2 分裂 / A2–P2** | 吸气生理性分裂;宽固定分裂提示房间隔缺损 | ✅ 已实现(Hilbert 双峰) |

> 阶段 3 全部为**启发式/近似**,用合成信号验证方向正确;真实临床数据上的
> 阈值标定与有监督校准属阶段 4。

### 🟡 阶段 4 — 阈值标定 + ML 分类(部分完成:工程特征 + 树模型基线)

**这一阶段真正的瓶颈是阈值标定,不是有没有 ML。**

阶段 1–3 的所有"疑似 XX"判定都依赖四个**未经真实数据标定**的经验阈值:
`murmur_thr=0.15`、`extra_thr=0.20`、`split_narrow_ms=45`、`sqi_thr=0.35`、
`conf_thr=0.30`、`hum_thr=0.80`。

**已完成一轮真实数据标定**:`calibrate.py` 在 CirCor DigiScope 上给出了
ROC 与工作点,结果见 [VALIDATION.md](VALIDATION.md)。核心发现是默认
`murmur_thr=0.15` 在真实数据上敏感度只有 **0.340**——工具漏掉 2/3 的杂音。
Youden 最优点在 0.041(敏感度 0.673/特异度 0.669)。

**但没有把默认值改过去**:CirCor 是儿童 + 数字听诊器,本项目面向成人 +
听诊器 + 咪头 + 声卡,阈值不跨人群/设备迁移。正确做法是各自标定:
`HeartSoundAnalyzer.from_json("thresholds.json", operating_point="sens80")`。

- **已实现**:`classifier.py` 把阶段 1–3 的全部 DSP/临床特征拼成 28 维向量,接
  scikit-learn `HistGradientBoosting`(原生支持 NaN,`class_weight="balanced"`)。
  `predict.py` 加载即用,且在信号质量不合格时**拒绝给出判定**。
- **真实数据**:`load_physionet2016()` + `--train-physionet <目录>` 一键在
  PhysioNet/CinC 2016 上训练并存权重。
- **更高上限(待做)**:mel 频谱 / MFCC / 小波时频图 + CNN / CRNN(或 transformer),
  输出校准概率 + 可疑心动周期;按挑战赛指标(加权准确率 / 代价度量)评估。

#### 怎么读合成数据上的交叉验证指标

早期版本报"准确率 0.96 / AUC 0.98"作为阶段成果。这个数字**没有说明力**:
当时的合成集用单个 `murmur_sys` 阈值就能达到 0.938,树模型只多 2.5 个百分点
——指标衡量的是合成器把两类分得多开,不是模型学到了什么。此外
`murmur_occupancy` 等特征当时只在超阈值时才计算,在正常样本上 100% 缺失、
异常样本上仅 15% 缺失,"是否缺失"本身就是标签的代理(单凭这一个缺失指示位
即可达 92.5%)。

现在做了三件事让指标可读:

1. 形状特征**无条件计算**,消除缺失模式泄漏;
2. 合成集的正常类混入 1/3 **高噪声但健康**的样本——这是真实采集中最主要的
   假阳性来源,模型必须学会用 `murmur_asymmetry` 区分"噪声"与"杂音";
3. `--demo` 同时打印**单特征阈值基线**作为对照。

当前结果:单阈值基线 0.713,树模型 0.963(平衡准确率 0.963,敏感度 0.925,
特异度 1.000),增益 +0.25。首要特征是 `murmur_asymmetry`(置换重要性 0.396,
第二名 0.083)。**这仍然只是合成数据上的管线验证,不能外推到真实心音。**

#### 真实数据上的方法学要求

- **按受试者分组交叉验证**。`cross_validate(..., groups=...)` 支持
  `StratifiedGroupKFold`。CinC 2016 的 REFERENCE.csv 不含受试者 ID,文件名
  前缀(a–f)只是来源子库;若同一受试者贡献多条录音,按录音随机切分会造成
  受试者级泄漏。拿不到受试者归属时,应把指标当作**乐观上界**。
- **不要只看 accuracy**。CinC 2016 正常:异常约 4:1,全判正常即得 ~0.8。
  已改为同时报平衡准确率、AUC、敏感度、特异度——筛查场景真正关心敏感度。
- **置换重要性要在留出集上算**,在训练集上算会系统性高估。

### 现成预训练模型现状(2026-06)
没有"pip 装好、加载即用、且在真实心音上验证过"的干净模型。最接近的:
- **CardioPHON**(2025):首个公开发布的心音自监督预训练基础模型,在 2022
  PhysioNet 心音挑战赛官方榜排名第一;需 clone 代码 + PyTorch。
- **PhysioNet 2022 参赛仓库**(SpectroHeart、parallel-hsmm-murmur、InceptionTime
  CNN 等):研究代码,权重不一定打包,需自行配环境。
- Hugging Face 多为心音→频谱图**数据集**,非即用模型。

> 结论:外部模型都要 clone + 配深度学习环境 + 常需自下数据,并不比训练省事。
> 本仓库的务实路径:demo 模型即时可用(验证流程),真实可用走 `--train-physionet`。

### 🔭 阶段 5 — 采集协议(常被忽略,但决定上限)
- 录**4 个标准听诊区**(主动脉/肺动脉/三尖瓣/二尖瓣),每区 ≥15s。
- 标注**呼吸相位**;安静环境;硬件低频平直(见 [HARDWARE.md](HARDWARE.md))。
- 单点录会丢失放射方向/动作维度——这是单麦克风的物理天花板。

## 不在范围内

- 监管/认证(SaMD):本项目定位个人/研究,**不对外提供诊断**。
- 需要影像/导管确诊的病变:听诊本身就无法替代超声心动图。

## 数据集获取(阶段 4)

- PhysioNet 需注册并同意使用条款后下载;遵守各数据集 license 与伦理要求。
- 训练代码与模型权重不入本仓库(见 `.gitignore`),按需另建训练工程。
