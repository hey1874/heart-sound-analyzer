# 路线图:走向"接近临床医生的听诊效果"

> 定位:个人/研究/学习原型(非医疗器械、不涉监管)。ML 走公开数据集。

## 现状

已完成**筛查级**能力:心率 BPM、SQI 信号质量门控、HSMM-lite 心音分段、
节律分析(CV/Poincaré/早搏)、杂音能量提示。详见 [ALGORITHM.md](ALGORITHM.md)。

## 期望与现实的校准

临床医生听诊在做的远不止"测心率+发现杂音":识别 S1/S2、分裂、额外音
(S3/S4、click、开瓣音、心包摩擦音);刻画杂音的**时相/形状/强度分级/音调/
位置+放射**;并借**呼吸、Valsalva、体位**等动作做鉴别。

**关键判断:**
- 纯手写 DSP 规则会触顶,**到不了临床级**。真正接近临床靠
  **准确分段(DSP)+ 大型标注心音库上训练的 ML 模型**。
- 令人鼓舞的事实:PCG 上训练的 AI 在**杂音检测**一项上,可**达到甚至超过
  非专科医生**听诊。所以"接近临床"在**正常/异常、杂音有无**这层**可达**;
  复刻专科医生的**完整定性+定位+动作鉴别**目前**达不到**,且单麦克风单部位
  在物理上就缺了放射方向和动作维度。

## 分阶段路线(由实到虚)

### ✅ 阶段 1 — SQI 信号质量门控(已完成)
分析前剔除摩擦/运动/过载污染段,立刻降假阳。工程量最小、收益最快。

### ✅ 阶段 2 — HSMM 心音分段(已完成轻量无监督版)
时长约束的 S1→收缩→S2→舒张 分段,是所有下游临床特征的**地基**。
> 升级方向:接入有监督的 Springer 2016 逻辑回归发射模型(需标注训练),
> 在低 SQI / 心律失常下更稳。

### ✅ 阶段 3 — 可解释临床特征(在准分段之上,已完成)
| 特征 | 医学依据 | 状态 |
|---|---|---|
| **STI / LVET** | S1–S2 间期 ≈ 左室射血时间,反映收缩力(Weissler) | ✅ 已实现(近似) |
| **标准时域 HRV** | RMSSD、pNN50、SDNN(Task Force 1996);严格需 ECG | ✅ 已实现 |
| **杂音时相+形状** | 递增-递减(钻石形)→主动脉狭窄;全收缩期平台→MR/VSD | ✅ 已实现(启发式) |
| **频域 HRV(LF/HF)** | 自主神经平衡;需 ≥1–2 分钟稳定记录 | ✅ 已实现(带门控) |
| **S3/S4 奔马律** | 舒张期低频(15–60Hz)额外音 → 心衰/心室僵硬 | ✅ 已实现(启发式) |
| **S2 分裂 / A2–P2** | 吸气生理性分裂;宽固定分裂提示房间隔缺损 | ✅ 已实现(Hilbert 双峰) |

> 阶段 3 全部为**启发式/近似**,用合成信号验证方向正确;真实临床数据上的
> 阈值标定与有监督校准属阶段 4。

### 🟡 阶段 4 — ML 分类(部分完成:工程特征 + 树模型基线)
- **已实现**:`classifier.py` 把阶段 1–3 的全部 DSP/临床特征拼成向量,接
  scikit-learn `HistGradientBoosting`(原生支持 NaN)。合成数据 5 折交叉验证
  准确率 0.96 / AUC 0.98(仅验证管线)。`predict.py` 加载即用。
- **真实数据**:`load_physionet2016()` + `--train-physionet <目录>` 一键在
  PhysioNet/CinC 2016 上训练并存权重。
- **更高上限(待做)**:mel 频谱 / MFCC / 小波时频图 + CNN / CRNN(或 transformer),
  输出校准概率 + 可疑心动周期;按挑战赛指标(加权准确率 / 代价度量)评估。

### 现成预训练模型现状(2026-06)
没有"pip 装好、加载即用、且在真实心音上验证过"的干净模型。最接近的:
- **CardioPHON**(2025):首个公开发布的心音自监督预训练基础模型,在 2022
  PhysioNet 心音挑战赛官方榜排名第一;需 clone 代码 + PyTorch。
- **PhysioNet 2022 参赛仓库**(SpectroHeart、parallel-hsmm-murmur、InceptionTime
  CNN 等):研究代码,权重不一定打包,需自行配环境。
- Hugging Face 多为心音→频谱图**数据集**,非即用模型。

> 结论:外部模型都要 clone + 配深度学习环境 + 常需自下数据,并不比训练省事。
> 本仓库的务实路径:demo 模型即时可用(验证流程),真实可用走 `--train-physionet`。

### 🔭 阶段 5 — 采集协议(常被忽略,但决定上限)
- 录**4 个标准听诊区**(主动脉/肺动脉/三尖瓣/二尖瓣),每区 ≥15s。
- 标注**呼吸相位**;安静环境;硬件低频平直(见 [HARDWARE.md](HARDWARE.md))。
- 单点录会丢失放射方向/动作维度——这是单麦克风的物理天花板。

## 不在范围内

- 监管/认证(SaMD):本项目定位个人/研究,**不对外提供诊断**。
- 需要影像/导管确诊的病变:听诊本身就无法替代超声心动图。

## 数据集获取(阶段 4)

- PhysioNet 需注册并同意使用条款后下载;遵守各数据集 license 与伦理要求。
- 训练代码与模型权重不入本仓库(见 `.gitignore`),按需另建训练工程。
