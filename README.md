# 心音听诊分析 / Heart Sound Analyzer

通过(接听诊器的)麦克风实时采集心音,估计**心率(BPM)**、评估**节律规则性**、
给出**杂音能量提示**,并在分析前做**信号质量门控(SQI)**与**HSMM 心音分段**。

> ⚠️ **医疗免责**:本项目仅用于学习/研究/技术演示,**不是医疗器械**,
> 输出**不构成任何医学诊断**。如有健康问题请就医。详见 [LICENSE](LICENSE)。

---

## 它到底能做到什么(先读这一段)

以下数字来自 **[CirCor DigiScope](https://physionet.org/content/circor-heart-sound/1.0.3/)
真实标注数据**,不是合成信号。完整方法与复现步骤见
[docs/VALIDATION.md](docs/VALIDATION.md)。

> 🚨 **先读这条警告。** 下表全部是**同一数据源内部**的交叉验证。在
> [CinC 2016](https://physionet.org/content/challenge-2016/1.0.0/) 上做外部验证后
> 发现:同一套管线在**随机分折**下 AUC 0.878,而**留出一个未见过的来源**时只有
> **0.51–0.70**,相差 0.365。也就是说,内部指标很大一部分是在识别**设备**而非
> 病理。CirCor 训好的模型零样本迁移到 2016,树模型约 **0.56**、CNN 约 **0.64**。
>
> **下表应读作「同源条件下的上界」,不是你在自己硬件上能拿到的性能。**
>
> 但**来源固定时内部 AUC 可达 0.69–0.99**——病理信号确实在音频里,只是被设备
> 差异淹没了。所以务实路径不是找一个"通用模型",而是**用自己设备采的标注数据
> 重新训练**(`calibrate.py` 为此而设)。纯归一化/自动增益类的无标签补救试过,
> 修不好。详见 [外部验证](docs/VALIDATION.md#8-外部验证所有内部指标都严重高估)。

| 能力 | 真实数据上的表现 | 评价 |
|---|---|---|
| **S1/S2 分段** | F1 **0.931**,定位误差中位 0ms(均值 12ms) | ✅ 最扎实的一项 |
| **心率** | 通过门控的录音误差中位 **1.2 BPM**,粗差率 3% | ✅ 可用 |
| **信号质量门控** | 被拒录音的心率粗差率 40%,保留的仅 3% | ✅ 拦对了(代价:仅保留 46%) |
| **杂音检测**(工程特征) | AUC **0.876** | ⚠️ 手工特征的天花板 |
| **杂音检测**(频谱图+CNN) | AUC **0.948** | ✅ 可选路径,需 PyTorch |
| **收缩/舒张期时长** | 误差中位 **0.0ms**,绝对误差中位 11ms | ✅ 可用 |
| **正常/异常分类** | 按患者分组 AUC **0.901**(患者级) | ✅ 多区取均值 |
| **节律变异 / HRV** | 与真值相关系数仅 **0.40**,三档一致率 70% | ❌ **不可信,勿用于判心律失常** |

杂音检测原本只有 AUC 0.715(默认阈值下漏掉 2/3 的杂音)。两步改进:
**加 48 维频谱轮廓特征**(零新增依赖)把它推到 0.876,**换成对数梅尔谱 + CNN**
再推到 0.948。零依赖的那一步贡献了 2/3 的绝对增益。详见
[docs/VALIDATION.md](docs/VALIDATION.md#6-杂音检测从-0715-到-0948)。

> ⚠️ 上表中树模型一路的数字是**看着同一份交叉验证结果挑参数**得来的,偏乐观;
> 尚未在独立数据集上做外部验证。CNN 的 0.948 只训练过一次,相对干净。

### 能力边界

界限不在"DSP vs ML",而在**测量 vs 判定**:

| | 能力 | 现状 |
|---|---|---|
| **测量类** | 心率、收缩/舒张期时长、信号质量、S1/S2 分段 | 答案由信号唯一确定,纯 DSP 可做对,上表已验证 |
| **二阶统计量** | RR 变异 CV、SDNN/RMSSD/pNN50、Poincaré | ⚠️ 分段 F1 0.93 撑得住间期中位数,**撑不住变异性**——每个分段错误污染两个 RR |
| **判定类** | "有没有杂音"、"是不是 S3"、"正常/异常" | ⚠️ 依赖阈值,而阈值不跨人群/设备迁移 |

判定类卡住的**不是有没有 ML,而是阈值有没有标定**。用 `calibrate.py` 在你自己的
标注数据上标定,再用 `HeartSoundAnalyzer.from_json()` 加载:

```bash
python calibrate.py <CirCor目录> --out thresholds.json
```

```python
an = HeartSoundAnalyzer.from_json("thresholds.json", operating_point="sens80")
```

还有一类物理上就做不到:杂音形状→具体病变的对应。单麦克风单部位缺了放射方向
与呼吸/体位动作维度。

## 功能

| 能力 | 说明 |
|---|---|
| **心率 BPM** | 包络自相关 + 谐波确认 + 抛物线插值,带 0~1 置信度 |
| **信号质量 SQI** | 周期性 / 带内能量占比 / **50-60Hz 工频** / 削波四项综合,坏段自动门控 |
| **HSMM 分段** | 时长约束的 S1→收缩→S2→舒张 4 状态分段(Springer 2016 轻量无监督版) |
| **节律分析** | RR 变异系数 CV、Poincaré SD1/SD2、标准 HRV(SDNN/RMSSD/pNN50)、早搏计数 |
| **STI 收缩间期** | 收缩/舒张期时长与比值(≈LVET 近似) |
| **杂音提示** | 能量指数 + **噪声/杂音判别** + 形状(钻石/平台/递增/递减)与时相 |
| **S3/S4 奔马律** | 舒张期低频(15–60Hz)额外音检测 |
| **S2 分裂** | A2–P2 间期(Hilbert 双峰 + 突出度判据),宽固定分裂提示 ASD |
| **频域 HRV** | LF/HF 自主神经平衡(需 ≥100 个心动周期且 ≥120 秒,带门控) |
| **实时运行** | 索引式环形缓冲 + 周期分析,终端实时滚动输出 |
| **离线自测** | 内置合成心音,含**阴性对照**,无需麦克风即可验证;失败返回非零退出码 |

**先做链路体检**(接上硬件后、正式录音前):

```bash
python checkmic.py --list      # 列出输入设备
python checkmic.py             # 录 5 秒环境声,检查链路
```

「听诊器 → 咪头 → 3.5mm → 声卡」这条链路上有几个坑**不会报错**,只会让你拿到
"能出数但全是错的"结果:系统降噪/麦克风增强会在 100Hz 以上做高通,正好砍掉
S1/S2 主能量;声卡本身也可能在 50–100Hz 以下高通;还有工频、削波、AGC。
`checkmic.py` 从环境底噪的频谱形状反推这些问题:

```
✅ 输入电平: 峰值 -18.3 dBFS,动态范围合适
❌ 低频响应: 20-60Hz 比 200-400Hz 低 14 dB,链路存在高通。S1/S2 主能量在
             20-150Hz,会被砍掉。→ 关掉系统的降噪/麦克风增强;换低频平直的声卡
✅ 工频干扰: 50/60Hz 占 3%,干净
```

> Mac 的 3.5mm 是四段式耳麦口(CTIA),麦克风在**最外圈套环**上。普通三段式
> (TRS)麦克风插头插进去会被识别成耳机,录不到东西。

找位置的办法:先摸到**胸骨角**(胸骨上段的横向骨嵴),它平对第 2 肋,紧邻其下
就是第 2 肋间,由此往下数。示意图上画出了胸骨角、肋骨、锁骨中线与心脏轮廓,
听诊点的坐标**由肋间几何推算**(胸骨角平对第 2 肋、肋间距 19、第 n 肋间取
第 n 与 n+1 肋之中点),不是手工摆的。

> ⚠️ 示意图为**正面视角**(面对受检者),因此**图的右边 = 受检者的左侧**
> ——主动脉瓣区在胸骨右缘,画在图的左侧。图上已标出左右与肋间刻度,但
> **以文字定位为准**。
>
> ⚠️ 工具**无法判断你是否贴在正确位置**,它只能告诉你信号好不好。
> 代号 AV/PV/TV/MV 与 CirCor 数据集一致——录音时标上位置,数据才能直接
> 喂给 `calibrate.py` 标定。多区录音也是实测中投入产出比最高的改进
> (患者级 AUC 0.701 → 0.762),而且不需要任何额外硬件。

## 作为库调用

核心算法 `HeartSoundAnalyzer` 与采集完全解耦,可处理任意波形:

```python
import soundfile as sf                    # 读音频文件需额外:pip install soundfile
from heartsound import HeartSoundAnalyzer

x, fs = sf.read("recording.wav")          # 任意采样率
res = HeartSoundAnalyzer().analyze(x, fs)

if not res["reliable"]:                   # ← 先看这一项再用其余结果
    print("信号不可采信:", res["unreliable_reason"])
else:
    print(res["bpm"], res["confidence"])  # 心率 + 置信度
    print(res["sqi"])                     # 信号质量(含 hum 工频占比)
    print(res["rhythm"])                  # 节律指标
    print(res["murmur"])                  # 杂音提示(含 asymmetry / noise_suspect)
```

阈值可按自己的设备重新标定,不必改源码:

```python
HeartSoundAnalyzer(murmur_thr=0.22, sqi_thr=0.40, conf_thr=0.20)
```

`heartbeat.py` 仍可用(`from heartbeat import HeartSoundAnalyzer` 与
`python heartbeat.py` 都不变),它现在是指向 `heartsound` 包的兼容垫片。

```python
an = HeartSoundAnalyzer.from_json("thresholds.json", operating_point="sens80")
```

## 正常/异常分类(ML 基线)

把上述全部 DSP/临床特征拼成 28 维特征向量,接 scikit-learn 的
HistGradientBoosting(原生支持缺失值)做"正常 vs 异常"二分类。**加载即用**:

```bash
python classifier.py --demo           # 合成数据交叉验证 + 单阈值基线对照
python classifier.py --train-demo     # 生成 demo 模型(已随仓库提供)
python predict.py recording.wav       # 对一段录音预测
python predict.py --selftest          # 合成杂音信号自检
```

信号质量不合格时**拒绝给出判定**(退出码 2),而不是给一个自信的错误答案:

```
⛔ 信号质量不合格,不予判定:工频干扰(检查屏蔽/接地,或改用电池供电)
   SQI 0.24(周期性 0.24 / 带内占比 0.98 / 工频 0.95 / 削波 0.000)
   请改善采集后重录;确要看结果请加 --force(结果不可信)。
```

质量合格时:

```
判定: 异常   异常概率 [████████████████████] 1.00
心率 72 BPM (置信度 0.93) | SQI 0.65
杂音: 疑似收缩期杂音 (全收缩期平台型(疑二尖瓣反流/VSD类)/全收缩期)
```

> ⚠️ 随仓库的 `model_demo.joblib` 是**合成数据训练**的,仅验证流程、**勿信真实结果**。
> 要真正可用,在真实数据上训练:`python classifier.py --train-physionet <CirCor目录>`
> (PhysioNet/CinC 2016 格式)。现成预训练模型现状见 [docs/ROADMAP.md](docs/ROADMAP.md)。

> ⚠️ **安全**:`.joblib` 走 pickle 反序列化,**加载即执行**其中的代码。
> 只加载你自己训练的、或来源可信的模型文件。

**关于交叉验证指标的读法**:`--demo` 会同时打印**单特征阈值基线**作为对照。
如果树模型只比"一个手调阈值"高几个百分点,那么高指标衡量的是数据集本身多好分,
而不是模型的贡献。合成集上:单阈值 0.713,树模型 0.963。
**但真实数据上差距小得多**:CirCor 上单阈值 0.682、树模型 0.793(AUC 口径),
且按录音而非按患者切分会让 AUC 虚高 +0.01~0.03。见 [docs/VALIDATION.md](docs/VALIDATION.md)。

## 处理管线

```
                              ┌── 削波检测(必须在重采样前)
原始波形 ──────────────────────┤
   │                          └── 工频线谱检测 ─┐
   ↓                                            ↓
重采样(→2000Hz) → 带通(20–200Hz) → 香农能量包络 → 自相关+谐波确认 估心率
                                                      │
            ┌── SQI 信号质量门控 ←──────────────────────┤
            │      → reliable / unreliable_reason      │
            ├── HSMM 时长约束分段(S1/S2)─→ 节律分析(RR/Poincaré)
            └── 高频带(150–600Hz)能量 ──→ 杂音指数 + 时相不对称度判噪
```

算法细节见 [docs/ALGORITHM.md](docs/ALGORITHM.md)。

## 硬件

本项目针对**听诊器 + 驻极体咪头(如松下 WM-61A)+ 声卡**链路设计。
低频(20–150Hz)是心音主能量区,**声卡的低频高通是最大风险点**。
接线、供电、采样建议见 [docs/HARDWARE.md](docs/HARDWARE.md)。

## 走向"接近临床"的路线

当前是**筛查级原型**。要逼近临床医生的听诊效果,核心是
**准确分段 + 大型标注心音库上的阈值标定与 ML 模型**(PhysioNet CirCor 2022 / 2016)。
完整路线、医学依据与各阶段工作量见 [docs/ROADMAP.md](docs/ROADMAP.md)。
